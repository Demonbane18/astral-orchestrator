Support

Start with the public project record.

The README explains installation, the v3.2.0 modes including explicit opt-in Measured, and common setup questions. The issue tracker is the right place for reproducible bugs, confusing behavior, and improvement ideas.

Read the install guidance first

The repository README is the source for the two-command GitHub install, requirements, modes, and troubleshooting. The dry-run setup is optional guidance for people who also want native named profiles.

Open a useful issue

If the README does not answer the question, open a public issue at github.com/Demonbane18/astral-orchestrator/issues. A useful issue helps another person understand the problem without guessing.

  • Use a short title that describes what happened.
  • Say what you expected, what actually happened, and the exact steps that led there.
  • Include relevant operating system, Python, and Codex details when they affect the result.
  • Share error text or a small safe example when useful. Remove secrets, private files, access tokens, and personal information first.

What to expect

Astral Orchestrator is an independent open-source project. Issues are public and community-visible; a response or timeline is not guaranteed. Do not use the issue tracker for sensitive information or urgent requests.

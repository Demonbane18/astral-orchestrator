Start with the job in front of you

Astral Orchestrator is a local, open-source Codex plugin. Orbit is the recommended default for normal project work. Name another mode only when you want its documented contract, and expect Astral to raise safeguards when risk requires it.

Choose among eight modesFrom one-session Singularity to maximum-native-throughput Hypernova, with defaults and opt-ins kept explicit. Contribute safelyExact repository checks, scope boundaries, license, and preserved attribution.

Three operating principles

  1. Requested is not observed. A mode name or task name is a plan. Runtime evidence is what proves the model, effort, route, and state.
  2. No silent substitution. When an exact model, effort, native control, provider capability, or review contract is unavailable, Astral blocks or uses only the fallback that the selected mode explicitly permits.
  3. Safety outranks speed. Hypernova can maximize safe host-advertised capacity, but it cannot broaden scope, authorize external changes, or bypass Event Horizon confirmation gates.

The website and plugin add no project-operated backend, analytics, API key, or background service. A user-selected external Morph provider can still receive its bounded packet during inference; read Safety and privacy before routing sensitive work.

Privacy policy · 2026-08-03

A short, factual privacy policy.

Astral Orchestrator is a local, skills-only plugin. This page explains what this static website and the project do—and do not—collect.

Website data

This website has no analytics, no cookies, no accounts, no forms, and no intentional first-party data collection. It does not ask you to submit information.

Hosting

The website may be hosted by Vercel. Like most web hosts, Vercel may process ordinary request metadata, such as an IP address, browser information, and request time, under its own policy and operational settings.

The local plugin

Astral Orchestrator has no project-operated backend. The plugin does not independently collect prompts, files, API keys, or usage analytics. Its local tools are designed to work in your Codex and project environment rather than send data to a service run by this project.

Other services you choose

Codex/OpenAI, Vercel, GitHub, and any user-authorized tools can process information under their own terms, privacy policies, and settings. Review those services before using them, especially when a project contains sensitive material.

Changes and questions

This policy is dated 2026-08-03. Material updates will be reflected on this page. For public project questions, use the repository issue tracker; do not post private information there.

This is a plain-language project notice, not legal advice.

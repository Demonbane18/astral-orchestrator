A local Codex plugin

Turn a request into a checked result.

Astral Orchestrator gives a bigger task a clear path: one lead keeps the plan in view, the right worker handles the implementation, and the result is checked before it is handed back.

See the install command View the repository

What it does

A steadier way to ask Codex for help.

Instead of treating every request the same, Astral separates planning, implementation, checking, and review. You still decide the goal; Astral makes the work path easier to follow.

Built for real project work

Use it for code, documents, configuration, research artifacts, and other work that lives in a project folder. It is a skills-only local plugin, not a hosted service.

Careful about the route

Guided and Careful work require the configured route rather than quietly swapping to a different model or effort. Tiny, easy-to-reverse tasks can stay with Sol in Quick mode.

The work path

One lead, the right lane, then a fresh look.

This is a visual guide to the usual Guided or Careful route. Sol keeps the outcome and safety boundaries; Luna and Terra receive bounded work after that plan is settled.

01

Sol leads

Clarifies the outcome, plan, safety boundaries, and what success should look like.

02

Luna handles narrow work

Best for focused, repeatable tasks with a clear, settled instruction.

02

Terra handles context-heavy work

Best for broader implementation, integration, debugging, or careful refactoring.

03

Run checks, then ask for a fresh Sol review

The actual changes are inspected and relevant checks run before a separate Sol reviewer assesses the finished work.

The route is based on the work at hand. It is a practical workflow, not a promise that every task has the same result.

Get started

Install from the complete repository.

The dry run prints the planned commands first. The full install adds the local marketplace, plugin, and companion profiles without overwriting a different profile.

Copy this into a terminal

git clone https://github.com/Demonbane18/astral-orchestrator.git
cd astral-orchestrator
sh scripts/setup.sh --dry-run
sh scripts/setup.sh

You need Codex access to the configured Sol, Luna, and Terra models, plus Python 3.11 or newer. For complete setup and troubleshooting details, read the repository README.

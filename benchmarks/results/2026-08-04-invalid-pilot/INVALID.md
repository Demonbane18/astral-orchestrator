# Invalid exploratory pilot

Do not use this run to compare Astral Orchestrator with single-Sol.

A fresh review returned `rethink` because the run had four benchmark-design defects:

- Astral's internal reviewer ran before objective checks and its verdict did not control acceptance.
- Missing strategy telemetry could be represented as numeric zero.
- Sandbox modes were neither embedded nor validated in route evidence.
- Efficiency comparison estimates did not use the same ratio-of-means calculation as the displayed summaries.

The raw artifacts are retained for auditability only. The harness was corrected after this run, but no replacement benchmark was launched because the user stopped further token and time expenditure.
